  2. 图标 / 名称 / 颜色 / 备注锁死：页内设置里是一行固定行「🌬️ 478呼吸法　🔒 图标、名称、颜色与备注由系统固定，不可修改」，只剩「每天几组」「每组循环次数」两个能改；模块设置弹窗里也一并锁死（保存时强制写回默认值）。
  3. 新增「478呼吸法的介绍」：标题 + 引导语 + 6 张小卡（快速镇静 / 缓解焦虑 / 改善睡眠 / 提升专注 / 稳定血压 / 温和练肺）+ 底部一条「怎么做」（吸 4 → 屏 7 → 呼 8，一组 4 次循环约 1 分 16 秒）。
  4. 新增页内「数据统计」：右上四档日期切换（近 7 天 / 近 1 月 / 近 3 月 / 全部），三个完成度环（今日 / 区间 / 连续达标）+ 六个指标（区间完成组数、呼吸次数、达标天数、达标率、累计组数、累计呼吸次数）+ 每日趋势折线（全部档改画按月柱状）+ 达标算法说明。原「坚持小结」小卡并入这里。

  8. 次数口径：呼吸次数 = 组数 × 每组循环次数（当前设置折算历史），页面上写明了算法。
