改前 v198网格线写死 #f4eadb

改后 v199网格线走 var(--line)

改了什么

  • 网格线的颜色原来**写死在 JS 里**（stroke="#f4eadb"），深色主题下那条浅米白横线比文字还刺眼。
  • 现在改成挂 class="stt-grid"、由 CSS 的 .stt-grid{stroke:var(--line)} 接管 —— 与同一个 SVG 里已有的 .stt-ax{fill:var(--muted)} 同一套做法。
  • 浅色主题下 --line:#f0e4d1 与原值只差几个色阶（看不出变化，零风险）；深色下变 #2e3a4d，网格退到背景层，红折线与数据点更突出。
  • 这是共用组件：moveStatLineSvg() 全仓 5 个调用点 —— 478 页内统计、运动页趋势、统计页的喝水块 / 478 块 / 运动块，改一处全部跟着变。
  • 没动同一函数里的面积填充 rgba(220,38,38,.10)（10% 透明度很淡、不刺眼，改它要牵涉整个图表配色体系）。
