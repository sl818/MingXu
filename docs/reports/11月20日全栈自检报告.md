## 三、分级发现

### 〔P1〕统计页三个控件静默失效（已实测点击复现）

**发现**：数据统计页上「7 / 30 / 90 天」切换、「习惯时间线」展开、「戒烟 — 展开分析」三个按钮点击后无任何反应，且**不报错、不提示**。

**证据**（真浏览器点击，非静态推断）：

| 操作          | 期望               | 实测                           |
| ----------- | ---------------- | ---------------------------- |
| 点「7 天」      | 副标题变「近 7 天」、按钮高亮 | 副标题仍为「近 30 天」，按钮无 `active` 类 |
| 点「展开分析」（戒烟） | 按钮变「收起分析」并展开时段图  | 文案与内容均不变                     |

**根因**（`index.html`）：页面渲染的是 `data-act="set-stats-range"` / `stats-log-toggle` / `stats-quit-fold`，但处理器表里写成了 `set-statk-range`(13865) / `statk-log-toggle`(14345) / `statk-quit-fold`(14357)。分发逻辑是 `const fn = ACTIONS[el.dataset.act]; if (fn) …` —— 键不存在就**静默跳过**，所以永远不报错。

连带后果：`statsRange` 只有 13868 一处赋值 → 永远 30 天；`statsLogOpen` 只有 14346 一处 → 时间线永远只显示 5 条；`statsQuitOpen` 只有 14358 一处 → 戒烟分析永远折叠。

**为什么回归没抓到**：v127.1 修过一次同类问题（注释还留着：「分段控件之前只有 data-act 没有处理器」），但只补了 `stats-habit-tab` / `stats-med-tab`(14973/14974)，这两个是**重复键**——`statk-habit-tab`(14349) 与 `statk-med-tab`(14353) 成了死键，所以 tab 能用、range/log/quit 不能用。e2e 恰好只覆盖了 tab。

**影响**：三项功能对陛下等于不存在；若按 90 天复盘，看到的是 30 天数据而界面无任何提示（**读到的数是错的**，比"点不动"更值得警惕）。

**修法**：把这 5 个键统一改名（`statk-` → `stats-`），删掉 14349/14353 两个重复死键；补 3 条 e2e 断言（点 range 后校验副标题变化、点 quit-fold 后校验按钮文案翻转）。改动量约 6 行。

### 〔P1〕`/docs/` 内部工程文档公网可读

**发现**：`/docs/DEPLOY.md`、`BACKEND.md`、`HANDOFF.md`、`FRONTEND.md` 直接返回 200（21–65KB）。

**证据**：四份文件可匿名下载；内容含站点目录 `/www/wwwroot/todo`、PHP 解释器绝对路径 `/www/server/php/82/bin/php`、每分钟 cron 的具体命令、全部 `api.php?action=*` 接口表与库表字段说明。  
**已核实不含**：真实数据库口令、SMTP 授权码、API Key、管理员邮箱、邀请码（命中项全是 `you@example.com` 一类占位符）。

**影响**：攻击者省掉全部侦察成本即可拿到完整攻击面清单；也暴露了未在界面出现的接口名（如 `admin_settings_save`、`force`）。单条子域下的信息泄露，不构成直接入侵。

**修法**：nginx 加 `location ^~ /docs/ { return 404; }`（与现有 `/api/`、`/tools/` 的 404 拦截同一手法），或把 `docs/` 移出站点根。二选一，1 分钟。

### 〔P2〕安全响应头：冲突与缺失

**证据**（同一次响应内）：

```
X-Frame-Options: DENY          ← PHP 输出
X-Content-Type-Options: nosniff
X-Content-Type-Options: nosniff ← 重复
X-Frame-Options: SAMEORIGIN    ← nginx 追加
```

- `X-Frame-Options` 出现两个互相矛盾的值，浏览器取哪个取决于实现（Chrome 取第一个 DENY，属于从严，暂无风险，但语义已不可控）。
- `X-Content-Type-Options` 重复两次。
- 缺 `Content-Security-Policy`、缺 `Permissions-Policy`。
- HSTS 有 `max-age=31536000`，但缺 `includeSubDomains` / `preload`。

**修法**：PHP 侧去掉自己那两个头，统一由 nginx 一处输出（`add_header` 需注意 4xx 也要生效，用 `always`）；HSTS 视子域情况加 `includeSubDomains`。CSP 对本项目意义有限——单文件内联脚本占大头，硬上只能 `unsafe-inline`，收益低，可暂不做。

### 〔P2〕仅 HTTP/1.1，无 HTTP/2

**证据**：`curl -w %{http_version}` → `1.1`；首页带动 7 个静态请求（1 CSS 主包 70KB + 5 皮肤表 + SW）。  
**影响**：当前暖启动 FCP 约 0.67s，尚可接受；但 HTTP/1.1 下 6 个 CSS 并发抢连接，弱网下会明显放大。  
**修法**：宝塔站点开 HTTP/2（一行 `listen 443 ssl http2;` + reload），零代码改动。

### 〔P2〕单文件体量与 CSS 重复定义

**证据**：

- `index.html` 728,249 B（633KB 为内联 JS），15k+ 行；`assets/app.css` 70KB；6 张样式表。

- 24 处 `innerHTML`，328 处 `esc()`。

**修法**：不改架构，先在加样式时搜同名选择器（现有 342 条可定期用脚本列出）。真正收敛留给 CSS 外移那一轮。
