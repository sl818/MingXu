## 3. 红标规则（与旧规范的差异）

- 旧：一屏红不超过两处。
- 新：**红 = 还没做完**。今天未完成、逾期、失守 → 数值与主按钮用红；已完成 / 达标 / 进行中过一半 → 中性色。
- 为免糊成一片，红只落在**数值 + 主按钮 + 进度段**上，卡片描边与容器保持中性。
- 逾期条目额外用红标签（如「今天」）与红色副标文字。

## 4. 今日页五张常驻卡：结构冻结清单

五张卡的原版结构、字段、文案、按钮位置**一律不动**，只改颜色、圆角（统一 12px）、描边与字号间距。每张卡的「标志性图形」必须保留。

### 4.1 戒烟（每天保持 0 根）
图标 + 标题 + 副标 + 「常驻」徽标 → 「今天记了 N 次」大数字 + 一行说明 → **10×2 记录矩阵**（每格一次记录）→ 虚线提示条「昨天这包还剩 X 支 · 没记的可以补 [补记]」→ 两条圆点元信息（这包开了多久 / 还剩几支；累计几天 / 最长几天）→ 一句鼓励文案 → 底部「点一根 / 忍一次 / 撤销」。

### 4.2 喝水（9 杯 · 2300 ml）
右上「近 7 天均 N ml」+ 迷你柱 → 大数字「750 / 2300 ml」→ 「还差 X ml · N 杯」→ **分段进度条**（每段≈1 杯）→ 提示条「该喝水了 · 已隔 X 小时 Y 分」→ **06–21 时间轴 + 当前时刻标记**→ 底部三连（离 22:00 还有多久 / 还差几杯 / 建议每 18 分钟一杯）→「＋一杯 250 ml」全宽 + 「−」。

### 4.3 运动（每天 1 次 · 目标 10,000 步）
图标 + 标题 + 副标 → 「还没开始」大字 + 平时几点运动 → 「连续 0 天 · 本月 0 天」→ 右侧**虚线圆环 0/7 本周** → 「距本周结束还有 1 天」→「完成运动 / 撤销」。

### 4.4 478 呼吸法（每天一组 · 4 次循环 · 约 1 分 16 秒）
图标 + 标题 + 副标 → 「还没开始」+ 建议时间说明 → **正弦波曲线**（4 个循环）→ 两端标注「×4 次循环」「吸 4 · 屏 7 · 呼 8 · 共 1 分 16 秒」→「本周 0/7 天 · 累计 N 组」→「开始练习 / 撤销」。

### 4.5 用药（20 种药）
图标 + 标题 + 「N 种药」→ 「0 / 16 次」→「该服 06:30 的药了 · 某某片」→ **药品横向 chip 列表**（可左右翻页）→ 当前药品卡（名称 / 1 片·随餐·第 99 天 / 1-10 分页 / 08:00 20:00 时间 chip）→ 「按需」药品清单 → 库存告警（红字，如「索脲右胺 仅剩 3 天」）→「查看详细 / 记录 06:30」。

## 5.10 非常驻习惯卡 v2 落地（v142）

**边界（陛下明确）**：喝水 / 戒烟 / 运动 / 478 / 用药 是常驻模块，各自有卡片；
本节只改「其他习惯」（`habitCard(h, d, false)` 这一条路径）。`habitCard` 在入口分流：
`!compact && !isSmoke(h) && !h.med` 走 `habitCardV2`，其余仍走旧骨架。

### 结构
3px 身份色顶条 + 标题前同色圆点 → 标题 / `养成|戒除` 徽标 + 节奏 + 本周 N/7 →
右上状态徽标 → 七日条（周一起，7 等分）→ 副行（点阵 / 戒除得失 / 连续天数）→
`未完成 | 完成` → 备注。

### 改了什么

| 项 | 旧 | 新 |
|---|---|---|
| 身份色 | 只有 `--hc` 变量，无可见表达 | 顶部 3px 条 + 7px 圆点（深色下按 70% 混白提亮） |
| 周条 | 滚动最近 7 天，周日在第一格 | **自然周**（周一→周日）固定七列，`grid repeat(7,minmax(0,1fr))` |
| 圈内符号 | 纯色块 | 完成 ✓ / 未完成 ✕ / 部分半格 / 无记录空 |
| 状态文案 | 已完成 / 进行中 / 待打卡 / 今天守住了 | 今日待打卡 / 今日已完成 / 今日未完成 |
| 动作 | 单按钮 toggle | 未完成（左）+ 完成（右），均带撤销语义 |
| 戒除次数 | 「今天 N 次」裸数字 | `今日失守 N 次` + N 个 5px 红点（>5 显示 +N） |

### 新增数据字段 `state.skips`
`{日期: {习惯id: 1}}`，表示「明确记为未完成」。
**为什么不能塞进 checks**：`setCount(0)` 会删键，存不住「0」这个判断；
而「没记录」与「明确没做」在周条上必须区分（空 vs ✕）。

按项目规矩改了三处：
- `normalizeState` → `normalizeSkips()`（只留合法日期与真值键）
- `mergeStates` → 复用 `mergeByDay`（0/1 逐键取大，与 checks 同构）
- `repairBackup` → 不改，靠「不认识顶层键原样带过」的兜底

测试：`node e2e/test-merge.mjs` 从 7 条扩到 10 条，新增场景 H（按天并集）/ I（一侧无此字段）。

### 踩坑记录
1. `app.css` 的 `.habit-week{margin-left:auto}`（旧卡靠它右对齐）在纵向 flex 里会压掉 stretch，
   新栅格宽度退化成 max-content（7×24px 挤在中间）。必须显式 `width:100%;margin:0`。
2. 戒除卡在「无记录」时既不能写「今日守住」（与「今日待打卡」打架），也不能留空整行——
   最终选择整条不渲染，靠右上徽标表达。
3. Playwright `add_init_script` 设 `data-theme` 会被 HTML 上的 `data-theme="light"` 覆盖，
   深浅两图会一模一样；改主题必须点按钮或硬编码 HTML。
4. 切主题后立刻 full_page 截图会拍到 250ms 背景过渡的中间值（半页奶油半页藏青）。

- 周条不可点击：补记历史仍走日历页，避免卡片上再开一条写路径。

## 5.11 v142 线上核对与修正（v143）

线上实测 v142：`app.css?v=142` + `theme-v2.css?v=142`，SW `lifeboard-shell-v142`，零 pageerror。

### 抓到的缺陷：一张卡讲两套话

逐卡读 DOM 后发现 4 张戒除卡同时出现：

| 位置 | 值 |
|---|---|
| 右上徽标 | 今日待打卡 |
| 本周计数 | 7/7 |
| 连续天数 | 29 天 |
| 七个圈 | 全空 |

根因是两套判定并存：`habitWeekDone` 读 `met()`（戒除 = 没失守即达标），
而圈与徽标读「有没有显式记录」。戒除的达标本来就是隐式的，两者必然打架。

### 修法：判定收成一个函数

新增 `habitDayMark(h, ds, d)` → `done | fail | part | none | future`。
周条的圈、本周计数、徽标全部只认它，物理上不可能再对不上。

戒除的规则写死为：**没记失守 = 守住**；`ds < quitStartDay(h)` 之前算「还没开始」。
这条是按产品原有语义来的（v79 起的「不点 = 一直守着」，也是「连续 N 天」的来源），
若改成「必须显式确认」，会让所有戒除用户的连续天数归零，属于产品变更而非主题变更。

同时把 `habit-ok` 的戒除分支改成「只撤销今天的失守」，不再写 `r` 事件——
没有「确认守住」这个动作，就不该产生一条记录。
