## 1. 名字

| 项 | 值 |
| --- | --- |
| 中文名 | **明序** |
| 英文名 | **Mingxu** |
| 读法 | míng xù（英文按拼音读，不分写、不写成 Ming Xu） |
| 旧名 | 晚风 Todo（即日起停用） |

**释义**：明晰诸事，井然有序。

- **明** —— 明晰、清楚、显明。工具的第一层价值：把脑中零散模糊的事务提取出来，
  一目了然，消除遗忘与信息混乱。也代表清醒、审慎，契合严肃认真的调性。
- **序** —— 次序、排布、流程。Todo 的核心：给任务划定先后、梳理优先级，建立执行秩序，
  不是单纯罗列清单。
- **合起来**：明是前提，序是结果。语义链条是「先看清，再有序」，
  对应这个工具的使用逻辑：记录（明）→ 复盘（序）→ 调整（再明）。

**起名的三个约束（原文）**：全部常用汉字、读音顺口、输入简单；克制素雅，不偏文艺抒情，
适合开源工程项目；与市面上大量「简、知、星、待」类待办工具形成区分。

### 4.2 Logo 方向（本稿补充，待定稿）

现有图标是「深绿底 + 米色圆环、右半实心 + 一颗金点」，视觉上像「进度 + 一点阳光」，
能表达「记录」，但**表达不出「序」**。新 logo 建议保留血缘、补上第二层意思：

| 方向 | 构成 | 对应字义 | 备注 |
| --- | --- | --- | --- |
| **A（推荐）** | 圆环内三道由短到长的横线，右端对齐 | 序 = 递增的次序；圆 = 明（日轮） | 最像「仪表盘」，缩到 16px 仍看得出三道杠 |
| B | 「明」字右半（月）几何化成竖条 + 日轮圆点 | 直接取字 | 识别快，但偏「文创」，与工程调性略远 |
| C | 方形印章 + 内部斜向排列的短竖线 | 序 = 排布；印章 = 克制、正式 | 最严肃，但小尺寸容易糊 |

**硬约束**：单色可还原（能压成纯黑/纯白）；maskable 版本图形占比 ≤ 60%（安全区内）；
16×16 下仍能分辨；不用渐变、不用描边细于 1/16 边长的线条。

## 5. 用词禁忌

1. **不写成 `Ming Xu`**，两字连写；需要分词时用 `Mingxu`。
2. **不英译品牌名**（不要写成 `Clear Order`、`Orderly`）。
3. **不简称**「明序待办」「明序清单」——名称后面跟冒号或破折号，不跟品类词当后缀。
4. 中文正文里出现品牌名时**不加引号、不加空格**：「打开明序」，不是「打开 明序」。
5. 旧名「晚风」只保留在**作者署名**位置（如果用户要求保留），品牌位一律替换。
