卡片用的是线上真实 class 与 assets/app.css + assets/theme-v2.css， 所见即正式环境的视觉。只有「周条不需要做」和「节奏四选一」是本方案新增的两处。

一、今日页 · 小习惯 三张卡代表三种节奏

每天型照旧；周一三五 今天周六，卡片画虚线「不需要做」，不进今日待办； 每周 3 次 做到 2 次后仍然出现（还差 1 次），凑满后自动进「已完成」并折叠，不会从界面消失。 点下面的「完成 / 撤销」会实时改写卡片与周条。

二、周条三种态的对照 新增只加了虚线态

原来只有「做了 / 未做 / 部分 / 未来」四种；周期化之后必须能表达 「今天不需要做」， 否则用户会把空白误读成漏打卡。虚线态沿用同一套圆点尺寸与间距，不新增尺寸。

三、新建 / 编辑表单 · 节奏区块 只加这一块

表单不重构，只在「目标次数 / 天」上面插入四张节奏卡。底部的预览句实时跟随， 把「多久做一次、每次多少、这周还差几次」一次讲清。

四、指标口径 周期型不进入今日完成率

今日完成率的分母仍然只算日型习惯，周期型单列「本周节奏」。 这样日历、横幅、统计三处的口径一处都不用改——这是本方案最重要的取舍。

今日待办1 / 3 已完成
今日完成率33%
本周节奏0 / 1 项进行中
连续达标12 天

数字与上面三张卡对应（示例只放了 3 个习惯，所以分母很小）。第三张卡是新增的： 只统计弹性配额型（每周 N 次），不上今日完成率的分母；「周一三五」属于日型，只是非选中日不算欠账。
