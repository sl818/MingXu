# 线上环境测试脚本

在**真实站点**上跑的端到端测试，走真实 UI，不 mock 接口。

## 凭据

不入库。运行前设置环境变量：

```bash
export LIVE_EMAIL='你的测试账号'
export LIVE_PWD='对应密码'
export LIVE_BASE='https://your-domain.example/'   # 可选，默认就是它
```

## 四个脚本

| 脚本 | 作用 | 是否会写数据 |
|---|---|---|
| `pc_final.py` | 桌面端（1440×950）渲染 + 交互 + 完成率核对 | 会（打卡、记服药、推进待办） |
| `mobile.py` | 移动端（390×844 触摸）全页面 + 热区 + 交互 | 会少量（打卡 1 次） |
| `chain.py` | 功能衔接链路（日历补记 / 搜索跳转 / 皮肤布局 / 编辑弹窗） | 不写数据 |
| `mkdata.py` | 造测试数据（用药 / 待办 / 随笔 / 体重 / 习惯） | **大量写入** |

`mkdata.py` 用法：`python mkdata.py meds|tasks|extras`。
**只在全新的测试账号上跑**，否则会造出重复数据。

## 注意

- 断言里凡涉及"数量"的都用**从云端重算**，不要写死数字——反复跑会累计副作用
  （每次运行会推进 1 条待办、多记 1 次服药）。
- 热区判定要用 `max(元素自身尺寸, ::after 尺寸)`；命中测试要排除固定悬浮层遮挡。
- 移动端侧栏是隐藏的，`[data-nav]` 会命中 2 个节点，必须点 `offsetParent !== null` 的那个。
